# tethys

An underwater exploration game in one three.js file: no tech, no oxygen — swimming, an ecology, predators, a surface to breach and land to flop
onto, played as one animal of an alien convergent-evolution roster and, when it dies, as its child. Everything is procedural; nothing is loaded
but three.js.

- Play: https://william-are-buzbee.github.io/Game-Template-and-Library/games/tethys/ (a pull request's preview is `…/preview/<number>/games/tethys/`).
- Build and run: `node build.js`, then `node serve.js` and http://localhost:8080/dev.html (the files as they are) or `/tethys.html` (the build).
  `#low`/`#high` force a quality tier. The keys, the console helpers and the readout: CLAUDE.md, "Dev tools in the game".
- Working on it: **CLAUDE.md** (the rules), `HANDOFF.md` (now), `test/README.md` (every test and bench), `DESIGN.md` (each system).

This file is the long map: what every doc and every source file is for. CLAUDE.md has the short one.
